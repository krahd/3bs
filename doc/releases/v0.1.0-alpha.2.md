# v0.1.0-alpha.2

This alpha updates the native arm64 Audio Unit MIDI effect, VST3
MIDI-generating instrument, and standalone CoreMIDI application for macOS 13
and newer.

## Changes

- Added 12 dedicated voicing presets split across Independent, Chord, and
  Strum modes.
- Added deterministic straight-note duration grids with compatible migration
  for existing continuous-duration sessions.
- Moved time-signature and voicing controls into the revised Voices page.
- Added a tracked VS Code task that builds and installs both plugins locally.

## Verification

- Native arm64 Release build completed for AU, VST3, and standalone.
- Core, preset, star-catalogue, and plugin integration tests passed.
- Strict deep code-signature verification passed for all three ad-hoc-signed
  bundles.
- The Metal smoke test may skip when the build process exposes no Metal device.

## Known limitations

- Binaries are ad-hoc signed and not notarized.
- Logic AU and Ableton VST3 runtime validation remains incomplete.

Read the [installation guide](../INSTALL.md) before using a binary. Report
issues with the format, host, macOS version, and steps needed to reproduce the
problem.
