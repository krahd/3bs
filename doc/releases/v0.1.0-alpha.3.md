# v0.1.0-alpha.3

This release corrects the manufacturer branding in all native arm64 bundles.

## Changes

- Changed the AU and VST3 vendor name from `krahd` to `Tomas Laurenzo`.
- Changed bundle identifiers to the `com.tomaslaurenzo` namespace.
- Changed the plugin manufacturer code from `Krhd` to `Tmlz`.
- Applied the same company and bundle-identifier corrections to the standalone
  application.

## Compatibility note

Hosts may treat alpha.3 as a different plugin from alpha.2 because the AU
manufacturer code and bundle identifiers changed. This identity correction is
intentional while the project is in alpha.

Read the [installation guide](../INSTALL.md) before using a binary.
