# v0.1.0-alpha.1

The first downloadable alpha of The Three Body Solution provides native arm64
builds of the Audio Unit MIDI effect, VST3 MIDI-generating instrument, and
standalone CoreMIDI application for macOS 13 and newer.

## Included

- Fixed-step deterministic three-body simulation and generative MIDI mapping.
- Independent, chord, and strum voice modes.
- 24 deterministic factory systems and portable `.3bs` configuration files.
- Interactive Metal planetary scene, automatic framing, trajectory rendering,
  and live three-lane note history.
- Audio Unit, VST3, standalone, and complete-bundle ZIP archives.
- SHA-256 checksums, build provenance, licence, and third-party notices.

## Verification

- Native arm64 Release build completed for all three bundles.
- Core, factory-preset, star-catalogue, and plugin integration tests passed in
  fresh Debug and Release builds.
- Strict deep code-signature verification passed for all three ad-hoc-signed
  bundles.
- The Metal smoke test skipped because the packaging process exposed no Metal
  device.

## Known limitations

- Binaries are ad-hoc signed and not notarized.
- Logic AU discovery and runtime behavior have not completed validation.
- Ableton VST3 discovery and MIDI routing have not completed validation.
- Final renderer interaction checks and frame-time profiling remain pending.

Read the [installation guide](../INSTALL.md) before using a binary. Report
issues with the format, host, macOS version, and steps needed to reproduce the
problem.
